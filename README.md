# Leonoa Lab Site v6

Sitio web en Next.js + TypeScript + Tailwind CSS para **Leonoa Lab**.

Esta versión suaviza la dirección visual: fondo claro, colores vivos pero no futuristas, sin degradados en botones ni logo, y con una paleta más amable.

## Ejecutar

```bash
npm install
npm run dev
```

Abrir: http://localhost:3000

## Añadir posts

Edita `content/posts.ts` y añade un nuevo objeto al array `posts`.
